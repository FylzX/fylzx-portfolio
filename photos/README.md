# 摄影作品

网页只在 `public/gallery/` 生成缩略图，源文件保留在本目录。
常规浏览只请求缩略图；进入详情才请求 `photos/` 中对应的原图，切换选中项不会预加载原图。
如果缩略图不存在，浏览画面会直接回退到对应的原图。
缩略图优先以质量 90 输出，长边从 1400px 逐步缩到 1000px，保持不超过 500KiB。
必要时仅在 1000px 下将质量调整至 80–90；如果仍超出预算则报错，避免默默牺牲画质。
简单画面压缩后可能小于 200KiB，不会通过填充数据来增加传输体积。小尺寸源图不会放大。

照片直接放在本目录（不放入子目录），支持 JPG/JPEG、WebP、PNG。按文件名日期归入时间段，从早到晚排列，同一天按数字编号排序：

```text
2024-01-01-01.jpg
2024-01-01-02.webp
2024-01-02.png
```

无编号时视为当天第 0 张；同一日期和编号不能重复。日期从 2024 年开始，由根目录 `collections.json` 的起止月份决定分组，整个月不会拆开。空分组不显示，分类之间不循环，类内照片循环浏览。默认进入最新分类，选中最后一张。未来年份默认单独归年，可再手动配置。

可选描述放在同名 JSON 中。例如 `2024-01-01-01.jpg` 对应 `2024-01-01-01.json`：

```json
{
  "description": "这张照片的拍摄故事。\n可以分行书写。"
}
```

描述显示在 EXIF 信息下方，使用灰色文字。不提供 JSON 或 description 为空则不显示。描述作为纯文本渲染，不能插入 HTML。快门、ISO、光圈、焦距、相机、镜头和拍摄时间直接从照片的 EXIF 提取，缺失字段不会伪造；分类和排序始终以文件名为准。

开发服务器会监听照片及描述变化并刷新；发布前执行 `npm run build`。程序保留原照片，仅生成已纠正方向的缩略图。构建将原照片原样复制到 `dist/photos/` 供详情加载，浏览器按原图方向信息显示；缩略图不携带原始 EXIF，清单仅保留上述用于展示的摄影字段。

本目录已导入 101 张真实照片，原始文件保留在 `LrC out/`。测试图和演示描述已移至 `.test-output/demo-backup/`，不再参与作品展。无需运行 `npm run demo`。
